# Discovery Library

Discovery Library is a comprehensive digital library and learning support web application built with React, Vite, and Three.js. Tailored for Vocational Education and Training (VET) students and trainers (AIBTGlobal Education Hub), the platform offers direct access to training videos, session recordings, interactive APA 7th referencing tools, workshop scheduling, consultation bookings, and LLND resources.

## Features

- **Interactive 3D Ambient Canvas**: Built with Three.js, rendering dynamic orbiting academic books, glowing rings, icosahedron gem, and stardust particles responsive to pointer movement and scroll depth.
- **Hero & Live Sessions Alert**: Live session indicator highlighting upcoming scheduled webinars and clinics with countdown information.
- **Quick Library Search**: Global search (Ctrl+K or modal button) querying training videos, workshop dates, and compliance briefings in real time.
- **Resource Hub**: Quick pathways to Training Videos, Useful Academic Links & Tools, Session Recordings, and Upcoming Sessions.
- **Microsoft Word Masterclass**: Sequenced 11-lesson series preview for digital document creation and formatting.
- **Upcoming Sessions & RSVP**: Interactive timetable with dates, session types (Live session, Workshop, Webinar), and booking reminders.
- **Interactive APA 7th Referencing Tool**: One-click copying of formatted reference list entries and in-text citations for journals, webpages, blogs, and ebooks.
- **Multi-Route Navigation**: Deep-linkable hash navigation supporting `/resources`, `/videos`, `/sessions`, `/referencing`, `/links`, `/recordings`, `/newsletter`, `/llnd`, `/consultation`, and `/contact`.
- **Responsive & Accessible**: Touch-friendly drawer navigation, keyboard shortcuts, reduced-motion compliance, and high-contrast dark palette.

## Tech Stack

- **Framework**: React 19 + Vite
- **3D Graphics**: Three.js
- **Styling**: CSS custom properties, responsive glassmorphism, typography powered by Bricolage Grotesque, Google Sans Flex, and JetBrains Mono
- **Vector Graphics**: SVGR with custom SVG icon system
